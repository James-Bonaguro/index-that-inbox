# Mac Inbox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repoint the capture webhook at a new "Mac Inbox" Doc that shows newest entries first, shows screenshots in the Doc, summarizes links, and moves entries older than 14 days to an archive Doc.

**Architecture:** All behavior lives in `apps-script/Code.gs` (Apps Script V8). Node tests run it in a `vm` sandbox with fake Google services (`tests/load-gas.js`, `fakeWorkspace()` in `tests/code.test.js`). Shortcuts and the PWA are unchanged.

**Tech Stack:** Google Apps Script (DocumentApp, DriveApp, UrlFetchApp, ScriptApp, LockService), Node `node:test`, no dependencies.

**Spec:** `docs/superpowers/specs/2026-11-25-mac-inbox-design.md`

## Global Constraints

- No npm dependencies, no build step. Tests: `node --test tests/*.test.js`.
- Reply shape unchanged: `{ ok, id, tag, platform, docUrl, fileUrl }`; `INGEST_KEY`, payload and heading format `[TAG] Platform · EEE, MMM d, yyyy 'at' h:mm a` unchanged.
- Archive cutoff: 14 days. Inline image width: 300 px, height in proportion. Description cap: 300 characters.
- Top note text, exactly: `Newest first. Entries older than 14 days move to Mac Inbox Archive.`
- Nothing permanently deleted: an entry leaves the inbox only after its copy lands in the archive.
- Copy James reads: plain language, no em dashes. Never print or commit `INGEST_KEY`.

## Review Focus

1. Inline image insert throws (odd image, HEIC): the capture must still save with its Drive link. Test in Task 1.
2. A Heading 3 James typed by hand (not `[NOTE]/[LINK]/[ASSET]`) or the top note: archive leaves it alone. Test in Task 3.
3. Last entry has no trailing horizontal rule: archive treats the end of the body as its end. Test in Task 3.
4. Archive Doc can't be opened or copy throws: inbox is unchanged. Test in Task 3.
5. Running `authorize` twice: exactly one daily trigger. Test in Task 3.
