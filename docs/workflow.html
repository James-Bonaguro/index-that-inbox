If something doesn't land

First, check whether it arrived. Open the webhook's execution log. Each capture adds a doPost row. No new row means the phone never sent it.
"Not saved: Unauthorized"
The key in the Shortcut doesn't match. Re-import the Shortcut and paste the key from Apple Passwords.
No notification, no new row
Open Shortcuts on the iPhone and check that both Shortcuts are there. If not, wait a minute for iCloud, or re-import them on the Mac.
Index That missing from the Share menu
Share → scroll the app row to the end → More → Edit → add Index That to Favorites.
Back Tap does nothing
Settings → Accessibility → Touch → Back Tap → Double Tap → Index Thought. Works only while the phone is unlocked.
Inbox app stuck on "Key needed"
Tap the gear and paste the key again.
